Peanut2Shield flasher

Firmware v1.21. Use Chrome or Edge and a USB-C data cable. After install: close this tab, unplug, plug into a wall USB adapter, press RESET. Expect yellow, then purple blink. Then pair Shield, then TiVo remote.

Standard

Normal short taps. Use this unless you need TiviMate long-press.

Long-press

Hold Back / OK for TiviMate.

If Connect fails: hold BOOT, plug in, release, try again. If the PC beeps / reconnects: close this page, hold BOOT, install again, then wall power + RESET. Project: github.com/Wnt2Fly/Peanut2Shield
