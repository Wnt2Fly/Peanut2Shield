Peanut2Shield — USB update kit
=================================

NO PYTHON NEEDED on Windows. Everything is on this stick.

WINDOWS — do this
-----------------
1. Unplug Peanut2Shield from the TV.
2. Plug it into this PC with a USB-C DATA cable (not charge-only).
3. Double-click:  UPDATE.bat
4. Pick option 1 (normal) or 2 (board stuck on yellow).
5. When asked for COM port:
   - Open Device Manager (Win+X → Device Manager)
   - Expand "Ports (COM & LPT)"
   - Type the port shown, e.g. COM19
6. Wait for SUCCESS.
7. Press the small RESET button on the board once.
8. Unplug from PC and plug back into TV power (wall adapter is best).

WHICH OPTION?
-------------
  1  Normal update
     ONLY if the remote was working and the LED was NOT stuck on yellow.
     Keeps Shield and TiVo pairing when it works.

  2  Full fix  <-- use this if anything went wrong
     LED stays YELLOW forever, remote stopped working, or first-time setup.
     Clears the chip and re-flashes everything. Re-pair Shield + TiVo.

  Check VERSION.txt on the stick — must say v1.06 for the yellow-LED boot fix.
  If option 1 was used and the LED is now solid yellow, run option 2 with a v1.06 stick.

  Maintainer: run pack-usb-drive.bat on the build PC before copying usb-drive to a stick.
  The stick must contain firmware\update\firmware.bin (not just the scripts).

AFTER FLASH
-----------
  Purple slow blink   → pair Shield: Settings → Add accessory → Peanut2Shield
  Orange double-flash → pair TiVo: Power+TiVo, Vol− x3, TiVo, any button
  Solid green         → working

DO NOT hold the tiny BOOT button unless you mean to clear pairing:
  5 sec = forget TiVo    8 sec = forget Shield    10 sec = factory reset

NO COM PORT AFTER REBOOT?
-------------------------
Windows lost the port — common after a bad flash or yellow crash loop.

  1. Unplug 10 sec, try another USB port on the PC (data cable!).
  2. Device Manager — port may have a NEW number (COM19 not COM15).
  3. Still nothing? Hold BOOT, plug in USB, release BOOT after 2 sec.
     Then run UPDATE.bat option 2 right away.

LINUX
-----
  Read docs/linux.txt, then run ./UPDATE.sh

More detail: docs\windows.txt (Windows) or docs\linux.txt (Linux)

WHAT'S ON THIS STICK
--------------------
  UPDATE.bat / UPDATE.sh     — start here
  VERSION.txt                — firmware version
  firmware/update/           — app-only image (normal update)
  firmware/full/             — complete image (yellow LED / new board)
  tools/                     — flasher scripts + espflash.exe (Windows)
  docs/                      — longer guides
  pack/                      — for whoever built this kit (ignore)
