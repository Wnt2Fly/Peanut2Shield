Peanut2Shield — USB update kit
=================================

WINDOWS (no install needed)
  1. Read QUICK-START.txt
  2. Double-click UPDATE.bat

LINUX
  1. Read docs/linux.txt
  2. Run ./UPDATE.sh

WHAT'S ON THIS STICK
  UPDATE.bat / UPDATE.sh     — start here
  QUICK-START.txt            — short Windows guide
  VERSION.txt                — firmware version
  firmware/update/           — app-only image (normal update)
  firmware/full/             — complete image (yellow LED / new board)
  tools/                     — flasher scripts + espflash.exe (Windows)
  docs/                      — full Windows and Linux guides
  pack/                      — for the person who builds this kit (ignore)
