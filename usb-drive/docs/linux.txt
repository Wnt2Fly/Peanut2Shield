Peanut2Shield — Reflash guide (Linux)
======================================

Hardware: Waveshare ESP32-S3-Zero in the Peanut2Shield case
Firmware: see VERSION.txt in the kit root

-----------------------------------------------------------------------------
ONE-TIME SETUP
-----------------------------------------------------------------------------

Install Python 3 and esptool. Examples:

  Debian / Ubuntu / Raspberry Pi OS:
    sudo apt update
    sudo apt install python3 python3-pip
    pip3 install --user esptool

  Fedora:
    sudo dnf install python3 python3-pip
    pip3 install --user esptool

Serial port access:

    sudo usermod -aG dialout "$USER"
    # log out and back in (or reboot)

-----------------------------------------------------------------------------
UPDATE
-----------------------------------------------------------------------------

  cd /path/to/usb-drive
  chmod +x UPDATE.sh tools/linux/*.sh   # once
  ./UPDATE.sh

Pick 1 (normal) or 2 (full fix). Default port: /dev/ttyACM0

Or run directly:
  ./tools/linux/flash-update.sh
  ./tools/linux/flash-full.sh

-----------------------------------------------------------------------------
TROUBLESHOOTING
-----------------------------------------------------------------------------

"Permission denied" on /dev/ttyACM0
  → Add your user to the dialout group (see above).

"Failed to connect"
  → Unplug/replug USB, press RESET, retry.

-----------------------------------------------------------------------------
BUILD THIS KIT (MAINTAINER)
-----------------------------------------------------------------------------

From the project root:

  chmod +x usb-drive/pack/pack.sh
  ./usb-drive/pack/pack.sh

Copy the whole usb-drive folder to the stick.

Windows sticks include espflash.exe (no Python). Linux uses esptool via pip.
